เกี่ยวกับฉัน (About Me)

สวัสดีครับผม ปังปอนด์ ศริตวรรธน์ ยศเดชากิตติ์ นักเรียนชั้น ม.3/2 จากโรงเรียนจอมทอง จังหวัดเชียงใหม่ ผมมีความหลงใหลและสนใจเกี่ยวกับเทคโนโลยี การออกแบบโครงสร้างเว็บไซต์ รวมถึงการพัฒนาตนเองอย่าง continuous learning

นอกจากเรื่องวิชาการที่ผมมุ่งมั่นรักษาเกรดเฉลี่ยให้อยู่ในระดับสูงแล้ว ในเวลาว่างผมยังชอบสร้างสรรค์ผลงานผ่านงานอดิเรกที่หลากหลาย ทั้งการเขียนโค้ด วาดรูป และติดตามเทคโนโลยีใหม่ๆ บน GitHub ครับ
